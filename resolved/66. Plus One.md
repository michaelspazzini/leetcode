# Code
Soluzione del problema “Plus One” in cui un numero è rappresentato come un array di cifre. L’idea del codice è invertire l’array per semplificare la gestione del riporto, incrementare la prima cifra disponibile e propagare il carry quando si incontrano dei 9. Se tutte le cifre sono 9, viene aggiunto un nuovo elemento (1) in testa. Infine l’array viene nuovamente invertito per ottenere il risultato corretto.

## Soluzione 1
- Runtime: 0 ms
- Memory: 19.3 MB

```python3
class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        digits.reverse()
        i = 0
        rip = False

        while i < len(digits):
            if digits[i] == 9:
                digits[i] = 0
                rip = True
            elif digits[i] != 9 and rip:
                digits[i] +=1
                rip -=1
                break
            else:
                digits[i] +=1
                break
            i+=1
        
        if rip:
            digits.append(1)

        digits.reverse()
        return digits
```
